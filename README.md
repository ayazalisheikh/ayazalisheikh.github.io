# Ayaz Ali Shaikh — Personal Website

A responsive, bilingual (Sindhi/English) static website prepared for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — responsive design
- `script.js` — mobile navigation and language switch

## Publish with GitHub Pages
1. Open your repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from this folder (or drag the three files from the ZIP).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
7. GitHub will show the published website address in the Pages section.

## Important repository name
For a user-site address of `https://ayazshaikh6606-dev.github.io/`, the repository must be named exactly:
`ayazshaikh6606-dev.github.io`
Your currently linked repository ends with an extra hyphen (`...github.io-`). Rename it in **Settings → General → Repository name** before publishing if you want the clean user-site URL.
